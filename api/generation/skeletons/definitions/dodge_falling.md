# 游戏设计指南：躲避下落物游戏

## 核心玩法
玩家左右移动，接住好的物品（金币、星星），避开坏的物品（炸弹、陨石）。好物品加分，坏物品扣分或结束游戏。

## 游戏元素
- **玩家移动**: 左右方向键或鼠标控制，固定在屏幕底部
- **下落物生成**: 从屏幕顶部随机X坐标生成，向下掉落
- **好物品**: 金币（+10分）、星星（+50分）、爱心（+生命）
- **坏物品**: 炸弹（-50分或直接失败）、陨石（-生命）
- **下落速度**: 随游戏进行逐渐加快
- **生成频率**: 开始时稀疏，后期密集
- **生命系统**: 3-5条命，碰到坏物品减少

## 技术要点
下落物每帧Y坐标增加固定值。玩家与下落物碰撞时检查类型，好物品增加分数并移除，坏物品扣分或减生命。下落物超出屏幕底部时移除。
