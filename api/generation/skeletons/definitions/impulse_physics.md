# 游戏设计指南：物理游戏

## 核心玩法
玩家通过施加力或冲量控制物体运动。物体遵循物理规律（重力、摩擦、碰撞反弹）。目标是击中目标物或达到特定位置。

## 游戏元素
- **发射机制**: 鼠标拖动设置力度和角度，松开发射
- **重力系统**: 物体受持续向下的重力影响
- **碰撞反弹**: 物体碰到墙壁或其他物体时反弹，损失部分能量
- **摩擦力**: 物体在地面滑动时逐渐减速
- **目标物**: 需要击中或推倒的物体
- **障碍物**: 阻挡路径或需要利用的物体
- **关卡目标**: 用有限次数击中所有目标

## 技术要点
发射时根据鼠标拖动距离计算初速度。每帧应用重力加速度到垂直速度。碰撞时计算反弹角度和速度损失。物体速度低于阈值时停止运动。

## System Prompt
实现物理游戏：拖动发射、重力和摩擦、碰撞反弹、目标检测、关卡系统。
