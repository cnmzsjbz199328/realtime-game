# 游戏设计指南：射击游戏

## 核心玩法循环
1. 玩家控制飞船/角色在屏幕上移动
2. 自动或手动发射子弹
3. 敌人从屏幕边缘生成并移动
4. 击毁敌人获得分数和道具
5. 避开敌人和子弹，生存到关底BOSS

## 典型游戏元素

### 玩家系统
- **移动**: WASD或方向键，限制在屏幕内
- **射击**: 空格键或鼠标，可设置自动射击
- **生命**: 3-5条命，被击中减少
- **能量**: 可选的能量槽，用于特殊技能

### 敌人系统
- **小型敌人**: 直线移动，1-2发子弹击毁
- **中型敌人**: 曲线移动或射击，3-5发击毁
- **BOSS**: 多阶段血条，特殊攻击模式

### 子弹系统
- **玩家子弹**: 向上/前方直线飞行
- **敌人子弹**: 向玩家方向或预设模式
- **碰撞**: 子弹击中目标后消失

### 道具系统
- **武器升级**: 双发、三发、激光
- **护盾**: 临时无敌
- **炸弹**: 清屏攻击
- **分数道具**: 金币、星星

### 波次管理
- **时间轴生成**: 每X秒生成Y个敌人
- **编队**: 敌人以特定队形出现
- **难度曲线**: 敌人数量和速度递增

## 视觉风格建议
- **背景**: 滚动星空或城市景观
- **玩家**: 三角形飞船或霓虹角色
- **敌人**: 不同颜色区分类型（红=快，黄=强）
- **子弹**: 发光轨迹，拖尾效果
- **爆炸**: 粒子爆炸（20-30个粒子）
- **UI**: 屏幕顶部显示分数、生命、BOSS血条
