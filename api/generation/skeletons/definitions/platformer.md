# 游戏设计指南：平台跳跃游戏

## 核心玩法循环
1. 玩家在2D横向关卡中移动和跳跃
2. 受重力影响，需要精确控制落地
3. 收集物品、避开障碍、击败敌人
4. 到达终点进入下一关

## 典型游戏元素

### 玩家角色
- **移动**: 左右移动（WASD/方向键）
- **跳跃**: 空格键，支持二段跳或变高跳跃
- **状态**: 在地面/空中，速度，生命值
- **能力**: 可选冲刺、滑墙、攻击

### 物理系统
- **重力**: 持续向下加速（如 `vy += 0.5`）
- **地面检测**: 碰撞检测判断是否着地
- **跳跃**: 给予向上初速度（如 `vy = -12`）
- **摩擦**: 地面减速，空中保持动量

### 关卡设计
- **平台**: 可站立的固体平台
- **障碍**: 尖刺、陷阱（接触扣血）
- **收集品**: 金币、星星（加分）
- **敌人**: 巡逻型、跳跃型
- **终点**: 旗帜、传送门

### 难度递增
- **关卡1**: 简单平台，少量敌人
- **关卡2**: 移动平台，更多障碍
- **关卡3**: 精密跳跃，BOSS战

## 视觉风格建议
- **背景**: 渐变天空或深色太空
- **平台**: 霓虹边框，半透明填充
- **玩家**: 发光方块或简单角色
- **粒子**: 跳跃时脚下粒子，收集物品时爆炸
- **动画**: 跳跃时拉伸，着地时压缩
