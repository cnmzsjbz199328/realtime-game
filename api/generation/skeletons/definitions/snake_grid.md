# 游戏设计指南：贪吃蛇游戏

## 核心玩法
蛇在网格上移动，不能回头。吃食物后身体变长。撞墙或撞自己则游戏结束。分数随长度增加。

## 游戏元素

### 蛇系统
- **身体结构**: 由多个格子组成的链表，头部在最前，尾部在最后
- **移动方式**: 每隔固定帧数向当前方向移动一格，头部前进，尾部跟随
- **转向规则**: WASD 控制方向，但不能立即反向（例如向右移动时不能直接向左）
- **生长机制**: 吃到食物后，下次移动时尾部不缩短，身体增加一格

### 网格系统
- **格子尺寸**: 建议每格20像素
- **网格数量**: 对于800x600的画布，使用40列x30行
- **坐标系统**: 使用网格坐标而非像素坐标，便于碰撞检测

### 食物系统
- **生成位置**: 随机选择一个不与蛇身体重叠的格子
- **碰撞效果**: 蛇头与食物重叠时，蛇身体增长，分数增加，食物重新生成
- **视觉效果**: 可以添加闪烁或脉动动画

### 碰撞检测
- **边界碰撞**: 蛇头超出网格范围（小于0或大于最大值）
- **自身碰撞**: 蛇头的坐标与身体任意一段的坐标相同
- **食物碰撞**: 蛇头与食物的网格坐标相同

### 难度设计
- **简单模式**: 每10帧移动一格，速度较慢
- **中等模式**: 每6帧移动一格
- **困难模式**: 每3帧移动一格，反应时间极短

## 技术要点

### 移动逻辑
使用计时器控制移动频率。每次移动时，根据当前方向计算新的头部位置，将新头部添加到身体数组开头。如果没有吃到食物，移除数组末尾的尾部。

### 方向控制
监听键盘输入，但需要检查新方向是否与当前方向相反。例如，当前向右移动时，按下左键应该被忽略。

### 游戏状态
维护游戏状态（进行中/游戏结束），在碰撞发生时更新状态，停止游戏循环。

## 视觉风格建议
- **背景**: 深色背景，可选淡色网格线
- **蛇身**: 霓虹绿色，头部可以用不同颜色或更大尺寸区分
- **食物**: 红色或黄色，添加发光效果
- **分数显示**: 屏幕顶部，大字体显示当前分数和长度
- **游戏结束**: 半透明黑色遮罩，显示最终分数和重启提示
