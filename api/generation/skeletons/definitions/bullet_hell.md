# 游戏设计指南：弹幕游戏

## 核心玩法
玩家在密集弹幕中精确移动，避开所有子弹。敌人发射复杂的弹幕图案。玩家有极小的碰撞箱，需要记忆弹幕模式并找到安全路径。

## 游戏元素
- **精确碰撞**: 玩家的实际碰撞箱远小于视觉大小，通常只有中心的几个像素
- **弹幕模式**: 圆形扩散（360度均匀发射）、螺旋（旋转发射）、追踪弹（瞄准玩家）、激光扫射
- **慢动作**: 按住Shift键进入慢动作模式，降低移动速度但更精确
- **敌人阶段**: BOSS有多个攻击阶段，每个阶段不同的弹幕模式
- **得分系统**: 擦弹（子弹贴身飞过）获得额外分数
- **难度曲线**: 从简单的直线弹幕逐渐过渡到复杂的组合模式

## 技术要点
圆形弹幕通过循环生成，每个子弹的角度均匀分布。螺旋弹幕在每帧增加角度偏移。追踪弹计算玩家位置并设置子弹方向。碰撞检测使用圆形而非矩形，半径很小。

## System Prompt
实现弹幕游戏：复杂弹幕图案生成、精确圆形碰撞检测、慢动作效果、多阶段BOSS战。
