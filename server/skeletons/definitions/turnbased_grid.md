# 游戏设计指南：回合制网格游戏

## 核心玩法
玩家在网格上移动，每次移动算一回合。推动箱子到目标位置，或按特定规则移动。强调策略和规划，而非反应速度。

## 游戏元素
- **网格移动**: 按键后玩家移动一格，不是连续移动
- **箱子推动**: 玩家可以推动箱子，但不能拉动
- **墙壁**: 不可穿越的障碍
- **目标点**: 箱子需要被推到的位置
- **步数统计**: 记录玩家移动次数，越少越好
- **撤销功能**: 可选，允许玩家撤销上一步
- **关卡设计**: 多个关卡，难度递增

## 技术要点
使用回合制逻辑，只在按键时更新状态。检测玩家前方是否有箱子，如果有且箱子前方为空，则同时移动玩家和箱子。检查所有箱子是否都在目标点上，是则过关。

## System Prompt
实现回合制网格游戏：网格移动、箱子推动逻辑、目标检测、步数统计、关卡系统。
