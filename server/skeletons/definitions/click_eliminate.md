# 游戏设计指南：点击消除游戏

## 核心玩法
目标物随机出现在屏幕上，玩家需要快速点击消除。限时内消除越多分数越高。错误点击会扣分。

## 游戏元素
- **目标生成**: 在屏幕随机位置出现，停留1-3秒后消失
- **点击检测**: 鼠标点击时检查是否击中目标
- **好目标**: 点击得分（+10分），可能有不同颜色代表不同分值
- **坏目标**: 点击扣分（-20分）或减生命
- **连击系统**: 连续击中增加连击倍数，提高分数
- **时间限制**: 60秒倒计时，时间结束游戏结束
- **难度递增**: 目标出现速度加快，停留时间缩短

## 技术要点
使用计时器控制目标生成频率。鼠标点击时遍历所有活动目标，检查点击坐标是否在目标范围内。击中后移除目标，增加分数，更新连击数。

## System Prompt
实现点击消除游戏：随机目标生成、鼠标点击检测、连击系统、倒计时、难度递增。
