# 游戏设计指南：无尽奔跑游戏

## 核心玩法
屏幕自动向左滚动，玩家只能跳跃。避开障碍物，收集金币，速度逐渐增加。撞到障碍物则游戏结束。

## 游戏元素
- **自动滚动**: 所有障碍物和背景持续向左移动，速度逐渐加快
- **跳跃控制**: 空格键或点击屏幕跳跃，有重力和落地检测
- **障碍生成**: 从屏幕右侧随机生成，间隔合理确保可跳过
- **地面系统**: 持续滚动的地面，玩家在地面上奔跑
- **金币收集**: 空中和地面上的金币，收集增加分数
- **距离分数**: 根据奔跑距离自动增加分数
- **加速机制**: 每隔一段时间或距离，滚动速度增加

## 技术要点
维护一个滚动速度变量，每帧增加少量值实现加速。所有障碍物的X坐标减去滚动速度。当障碍物移出屏幕左侧时移除。跳跃使用垂直速度和重力模拟抛物线运动。

## System Prompt
实现无尽奔跑游戏：自动滚动、跳跃物理、障碍物生成、加速机制、距离计分。
